# reptime
Converts calisthenics work to screen time





## Stuff to change/improve the app

1. Add jump rope (calculate when feet leave ground) (every 30 seconds is 3.5 minutes of screen time)
2. Add local storage so data isn't lost with one refresh
3. For planks detect ground and make it more precise. It's up right not with your forearms on the ground.
4. The spend buttons don't work and add a seconds text box as well so you can spend for example 4 minutes and 50 seconds and so that you're not forced to round your spending time up or down.


5. Beginning to hang on the bar always counts a pull-up. To fix this, make the internal counter start at -1 but keep the display 0 until the internal counter is at 1 to avoid confusion.
